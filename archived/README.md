# Archived Implementations

This directory contains code that predates the current chapter-based course structure. Nothing
here is an input or dependency of the learner crate in `../type-exercise-starter/`.

- `type-exercise-ref/` is the completed expression-framework workspace retained for maintainer
  regression checks and post-chapter comparison.
- `legacy-days/` preserves eight point-in-time course crates. They are historical snapshots rather
  than one maintained workspace and are not part of current CI.

Learners should complete each chapter reflection before consulting these implementations.
